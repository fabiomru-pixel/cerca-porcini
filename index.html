Come ottenere il Client ID (una volta sola)
  1. Apri console.cloud.google.com e crea un progetto (es. “Cerca Porcini”).
  2. API e servizi → Libreria: abilita Google Drive API.
  3. Schermata consenso OAuth: tipo “Esterno”, aggiungi il tuo indirizzo Gmail tra gli utenti di test.
  4. Credenziali → Crea credenziali → ID client OAuth → Applicazione web.
  5. In Origini JavaScript autorizzate inserisci:
  6. Copia l’ID client e incollalo qui sopra.

L’app usa solo il permesso drive.file: vede esclusivamente la cartella “Cerca Porcini” che crea lei.

Offline e dati

I consigli sono stime basate sulle regole del gradiente termico, della pioggia e del timer del micelio: non garantiscono ritrovamenti. Rispetta la normativa regionale sulla raccolta (tesserino, limiti giornalieri, giorni consentiti) e i regolamenti delle aree protette. Dati: Open-Meteo, AWS Terrain Tiles, © OpenStreetMap, OpenTopoMap, EEA (aree protette).
